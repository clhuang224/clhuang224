# Hi, I'm Lynn

Front-end engineer from Taiwan, focused on maintainable architecture, reusable logic, and practical developer workflows.

I mainly work with Vue, React, and TypeScript, and I also contribute to open-source translation in Traditional Chinese.

## Featured projects

- [Finding the Bus](https://github.com/clhuang224/bus) - An ongoing bus lookup SPA built with React, Redux Toolkit, and MapLibre, focused on geolocation flow, map interaction, and data flow design.
- [PrePrompt](https://github.com/clhuang224/pre-prompt) - A local-first tool for replacing sensitive terms before pasting text into LLMs. Supports rule management, toggling, LocalStorage, and JSON import/export.

## Other projects

- [Mask Map](https://github.com/clhuang224/F2E_2nd/tree/master/W10_MaskMap) - A mask availability map built during the early COVID-19 period with Vue 2, Leaflet, and OpenStreetMap.
- [Queener](https://github.com/clhuang224/queener) - A work-in-progress puzzle game built with Vue and TypeScript, with a small game engine separated from the UI layer.
